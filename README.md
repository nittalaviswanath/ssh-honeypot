# SSH Honeypot

A Python-based SSH Honeypot built for cybersecurity learning, research, and attack analysis.

---

## Overview

This project emulates an SSH server to capture and analyze attacker behavior in a controlled environment.

Instead of giving attackers access to a real machine, the honeypot presents a fake SSH service that records login attempts and commands.
